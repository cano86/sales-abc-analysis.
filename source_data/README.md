# ABC-анализ ассортимента: выручка и маржа, диаграмма Парето, Excel-отчёт

Автоматизация отчётности по продажам на Python: сверка данных из двух источников,
расчёт KPI, двойной ABC-анализ (по выручке и по марже), диаграмма Парето
и формирование готового Excel-отчёта с несколькими листами.

## Задача

Заказчику нужно было быстро понимать, какие товары реально приносят деньги
и на чём фокусировать контроль. Ручные расчёты в Excel были трудоёмкими
и легко давали ошибки при пересчёте групп.

## Что сделано

1. **Подготовка данных** — объединение источников (продажи, возвраты, остатки),
   проверка схемы, обработка пропусков, контроль «чистой» выручки.
2. **KPI** — суммарная выручка, топ-5 городов, доля возвратов по городам
   с защитой от деления на ноль 
3. **ABC-анализ по выручке** — группировка по артикулам, сортировка,
   расчёт доли и накопительной доли (`cumsum`), распределение по группам
   A/B/C по порогам 80/95%.
4. **ABC-анализ по марже** — расчёт маржи (выручка минус закупочная стоимость)
   и повторный ABC по прибыли. Позволяет отличить «популярные» товары
   от «прибыльных»: найти позиции с высокой выручкой, но низкой маржой,
   и наоборот — «тихих героев».
5. **Диаграмма Парето** — столбики выручки + линия накопленной доли
   с границей группы A на уровне 80%.
6. **Excel-отчёт** — несколько листов: детальные данные, топ-5 городов,
   ABC по выручке, ABC по марже, сводка по группам.

## Результат

- Расчёт и формирование отчёта занимают минуты вместо часов ручного труда.
- Доли, накопительные суммы и границы групп считаются автоматически —
  исключён человеческий фактор.
- Разделение ассортимента на A/B/C по выручке и марже даёт базу
  для решений: управление запасами группы A, пересмотр цен и закупок
  по низкомаржинальным позициям.

## Логика ABC-анализа

Товары сортируются по выручке (или марже) от большего к меньшему.
Считается накопленная доля: сколько процентов выручки дают все товары
от начала списка до текущего включительно.

| Группа | Накопленная доля | Смысл |
|--------|------------------|-------|
| A      | до 80%           | Ключевые позиции: приоритетный контроль запасов и отгрузок |
| B      | 80–95%           | Стабильный «средний класс» |
| C      | 95–100%          | «Хвост»: кандидаты на пересмотр ассортимента |

## Детали реализации

- **Защита от деления на ноль** при расчёте доли возвратов: условное
  присваивание через маску 
- **Двойной ABC** — по выручке и по марже. Расхождения между группами
  показывают, где пересматривать ценовую и закупочную политику.
- **Проверки целостности**: сверка сумм между источниками до и после
  объединения, чтобы исключить потери или дублирование строк.
